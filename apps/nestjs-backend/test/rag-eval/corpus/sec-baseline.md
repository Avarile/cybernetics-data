# Security baseline

## Passwords and two-factor

Store every work password in the company Bitwarden vault. Two-factor authentication is mandatory on email, the code host, the cloud console and the database admin tools. Use an authenticator app or a hardware key, never SMS.

## Phishing

Forward suspicious emails to security@ and delete them. Never enter your credentials on a page reached from an email link. Reporting a mistake quickly is always better than hiding it.

## Devices

Laptops must have full-disk encryption turned on: FileVault on macOS and LUKS on Linux. Screens lock after five minutes of inactivity. A lost or stolen device must be reported within one hour so it can be wiped remotely.
